# Patiala Electrician Service Website

## Files
- index.html
- style.css
- script.js

## Run
Open `index.html` in a browser.

## Important
This is a front-end demo. Bookings are saved in the browser's localStorage. Before using it for real customers, connect a secure backend/database and a legitimate payment gateway.

## Google
After publishing, use Google Search Console to request indexing. Google indexing/ranking is not guaranteed or immediate.
